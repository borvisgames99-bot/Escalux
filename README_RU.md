# Escalux 1.0.1 — исходный проект

Самостоятельный мод Qevro для Minecraft Java 1.20.1 / Forge 47.x, Java 17. Это отдельный проект с собственным кодом, моделями и текстурами; он не является портом или копией другого мода.

## Реализовано в исходниках
- Два блока: эскалатор вверх и эскалатор вниз.
- Поворот при размещении по горизонтальному направлению взгляда.
- Перемещение игроков и мобов, стоящих на рабочей поверхности; приседание отключает ускорение.
- Настраиваемая базовая скорость в Forge common config.
- Ключ механика: ПКМ по эскалатору включает/выключает его; состояние хранится в block state.
- Анимированная текстура металлических ступеней через Minecraft texture animation.
- Встроенные металлические звуковые эффекты на движущемся эскалаторе.
- Автоматическое соединение соседних секций: распознавание соседей по сторонам и варианты моделей без дублирующихся общих поручней.
- Экран настроек Forge и переключатель «Интеграция с Create (BETA)».
- Необязательный reflection-only мост Create: при включённой настройке Escalux пытается прочитать скорость соседнего Create kinetic block entity через `getSpeed()`; при отсутствии подходящего блока используется базовая скорость. Create не является обязательной зависимостью.
- Рецепты крафта эскалаторов и ключа, локализации RU/EN, собственные текстуры и block/item models.

## Важное ограничение Create BETA
Текущий мост — экспериментальное считывание скорости с непосредственно соседнего кинетического блока Create. Это ещё не полноценный kinetic network component: эскалатор не передаёт обратно вращающий момент в сеть Create, не подключает вал напрямую через собственный kinetic block entity и не имеет специального интерфейса с Rotation Speed Controller. Для этого требуется отдельная реализация Create API и тестирование на конкретной версии Create для Forge 1.20.1.

## Соединение секций
Секции можно ставить вплотную, ориентируя их в одном направлении. Каждая секция работает самостоятельно. Автоматическое распознавание линии, скруглённые переходы, общие поручни без двойных боковин и автоматические стартовые/конечные рампы пока не реализованы.

## Сборка
Требуются JDK 17 и Gradle 8.x. В каталоге проекта:

```bash
gradle build
```

Готовый JAR после успешной сборки появится в `build/libs/`. Для запуска требуется Minecraft 1.20.1 и Forge 47.x. Create необязателен; для проверки BETA-моста установите совместимую версию Create для Forge 1.20.1.

## Проверка
JSON-ресурсы проверены на корректный синтаксис. Сборка Gradle и запуск в Minecraft в среде подготовки не выполнены: Gradle отсутствует, а загрузка дистрибутива и зависимостей заблокирована отсутствием сетевого доступа. Поэтому этот архив — обновлённый исходный проект, а не проверенный JAR.
