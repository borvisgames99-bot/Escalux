ESCALUX — КАК ПОЛУЧИТЬ JAR БЕЗ ПРОГРАММИРОВАНИЯ (Windows)

Важно: этот архив содержит ИСХОДНЫЙ ПРОЕКТ и настройку автоматической сборки.
Готового JAR внутри пока нет. JAR появится после успешной сборки на GitHub.

1. Откройте https://github.com и войдите или создайте бесплатный аккаунт.
2. Нажмите + (вверху справа) -> New repository.
3. Название репозитория: Escalux. Можно выбрать Private. Нажмите Create repository.
4. На странице пустого репозитория нажмите ссылку "uploading an existing file".
5. На компьютере распакуйте этот ZIP. Откройте получившуюся папку Escalux.
6. Перетащите ВСЕ файлы и папки ИЗНУТРИ папки Escalux в область загрузки GitHub.
   ВАЖНО: вместе с обычными файлами загрузите скрытую папку .github.
   Если проводник не показывает скрытые элементы: Вид -> Показать -> Скрытые элементы.
7. Внизу страницы GitHub нажмите Commit changes.
8. Откройте вкладку Actions в репозитории и выберите Build Escalux.
9. Дождитесь завершения сборки. Зелёная галочка означает, что сборка прошла.
10. Откройте завершённый запуск Build Escalux. Внизу страницы найдите Artifacts
    и скачайте Escalux-1.0.1. Распакуйте скачанный ZIP — внутри будет .jar.
11. Скопируйте .jar в папку .minecraft/mods. Нужны Minecraft 1.20.1 и Forge.

Если сборка завершится красным крестиком, пришлите скриншот страницы с ошибкой.
Не публикуйте и не устанавливайте JAR, если сборка не прошла.

Примечание: исходный проект ещё не был проверен запуском в Minecraft. Успешная
компиляция не гарантирует отсутствие игровых ошибок; после получения JAR его
нужно протестировать в отдельном профиле/мире.
